# LCE V1 Product Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the frozen standalone LCE V1 pipeline from Reference Memory through Semantic Blocks, snapshot-based structures, cognition worktrees, promotion, and accepted Understanding reads, with independent A1–A5 commits.

**Architecture:** Extend the existing contract-first LCE Core without importing MR. A local SQLite Reference Memory owns immutable Raw Evidence history and canonical Semantic Blocks; vectors, structures, snapshots, and worktrees are rebuildable derived state. The existing `LceCore` and `BaselineStorePort` remain the accepted linear Baseline/HEAD authority, while new adapters keep Memory and interpretation/promotion seams replaceable.

**Tech Stack:** Python 3.12+ (verified runtime Python 3.14.5), stdlib SQLite/JSON/hashlib/math, pytest, existing `lce` package, no MR dependency and no required runtime dependency beyond the standard library.

**Spec:** User-supplied `LCE-V1-CLOSE — A1–A5 MASTER EXECUTION`; frozen A0 context and source authority in `C:/projects/LCE/lab/diary_semantic_block_03` and `C:/projects/LCE/lab/diary_structure_06R`.

## Global Constraints

- Core cognition chain is `Raw Evidence → Semantic Block → Embedding / Cognition Space → Structure Discovery → Cognition Worktree → Accepted Baseline / HEAD → Accepted Understanding Read API`.
- Raw Evidence is never directly used as a cognition-point vector input; vectors/indexes derive only from canonical Semantic Blocks.
- Semantic Blocks are semantic units, not time units; semantic continuity continues, semantic switches split, multi-matter units split, recap/repetition deduplicates while preserving new information.
- Structures overlap, share points, reconnect, evolve, and permit point multi-membership; there is no exclusive cluster ontology and no TDA/H1 production authority.
- Distinguish point accumulation from structure-level higher-order relations; V1 supports `point → structure → higher-order candidate` only, with no unbounded recursion.
- Memory owns Raw Evidence validity/provenance/supersede/invalidation; LCE owns derived longitudinal cognition, structure observations, worktrees, and accepted Understanding revisions.
- Standalone LCE may use Reference Memory, an alternate Memory Port, or copied provenance/validity/supersede/anti-pollution patterns; LCE itself does not require Reference Memory.
- No MR integration, Body integration, C10, Persona, Agent identity, Intent, ActionPolicy, RuntimeBinding, or MR Scope implementation.
- Every stage is RED-first, targeted-test verified, full-regression verified, and independently committed before the next stage.
