# LCE V1 release and repair records

These files are retained as historical release/closure evidence for LCE V1.

They are **not** the primary entry point for the current research program. For current
research questions, experiments and verification, start with:

- ../../RESEARCH_OVERVIEW.md
- ../../research/OPEN_RESEARCH.md
- ../../research/FINDINGS.md
- ../../VERIFICATION.md
- ../../history/LCE_DECISION_EVOLUTION.md

A historical file named "closure" or "release" records the state of that V1 milestone; it
does not mean the broader longitudinal-cognition research problem is closed.
