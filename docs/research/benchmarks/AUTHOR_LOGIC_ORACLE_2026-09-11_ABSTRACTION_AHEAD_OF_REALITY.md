## 3. Top-level thesis

### T1 — Abstract capability must not be promoted into reality without preserving the missing conditions

The article's primary thesis is not that AGI/ASI will or will not happen. It is that reasoning becomes unreliable when verified local capability is promoted through successive abstractions while the enabling conditions at each layer are silently removed.

The full conditional chain is:

```text
verified local AI capability growth
    + unresolved system-level capabilities
        -> possibly more complete intelligence

more complete intelligence
    + resources / permission / infrastructure / execution
        -> possibly much larger real-world capability
```

The article rejects collapsing this into:

```text
local progress -> inevitable complete intelligence -> inevitable reality takeover
```

### T2 — Valuable abstraction preserves constraints and remains rerunnable

The article's later sections generalize the same reasoning method. High-level abstraction is useful when it identifies reusable structure across domains while retaining the conditions that can change the result. A new variable should trigger recomputation rather than being forced into an existing worldview.

## 4. Major reasoning chains

### C1 — Local competence is not system completeness

**Article support:** `P1 -> P2`

```text
math/code/tool/agent capability improves
        ↓
strong local competence is real
        ↓
complete intelligence additionally requires
memory / long-term consistency / self-calibration /
architecture judgment / reliability / other missing capabilities
        ↓
therefore complete intelligence remains a conditional projection
```

Key counterexample inside the article:

```text
can rapidly produce or modify large amounts of code
!=
can reliably decide which abstractions/code should never exist
```

This is a local-vs-global capability distinction, not an anti-AI claim.

### C2 — Intelligence is not physical execution

**Article support:** `P3`

```text
assume complete intelligence
        ↓
still requires permission + capital + energy + land + chips
+ industrial equipment + supply chains + construction time
+ law + organizational acceptance
        ↓
only then can information capability become large real-world capability
```

The physical world's slower time constants are treated as active constraints rather than evidence that AI progress is false.

### C3 — Narrative power often comes from deleting conditions rather than fabricating facts

**Article support:** `P4`, derived from `P1-P3`

```text
true fact A
true fact B
true fact C
+ omitted conditional dependencies
        ↓
"D is inevitable"
```

The author therefore prefers capability-boundary analysis:

```text
what can the system do?
under which conditions?
where does it fail?
```

over peak-capability storytelling.

### C4 — Interface simplicity hides substrate difficulty

**Article support:** `P5`

```text
civilization improves by encapsulating complex backend systems
        ↓
front-end invocation becomes easy
        ↓
users experience less of the substrate
        ↓
risk of confusing "easy to call" with "easy to build / maintain"
```

Examples span electricity, food delivery, banking, servers, roads, ports, mines, logistics, telecoms, data centers, settlement and law.

### C5 — AI extends encapsulation into understanding; normal efficiency and recovery capability can diverge

**Article support:** `P6`, dependent on `C4`

```text
AI/agents hide more implementation and reasoning work
        ↓
normal-operation productivity and reliability can rise
        ↓
human organizations reduce retained deep expertise
        ↓
multiple backups may still share one cognitive/technical origin
        ↓
normal efficiency ↑ while correlated-failure / recovery risk may also ↑
```

Critical distinction:

```text
ability to operate a system normally
!=
ability to reconstruct/recover it under exceptional failure
```

### C6 — Cheap knowledge retrieval changes what learning is for

**Article support:** `P7`, dependent on `C5`

```text
machine advantage in retrieval / breadth / memory / parallelism grows
        ↓
human competition on stored-fact quantity becomes structurally weak
        ↓
learning value shifts toward maintaining an internal coordinate system
for judging machine outputs
```

The investment analogy is explicit: competing with machine knowledge-retrieval speed is likened to a discretionary trader competing with quantitative systems on market-scanning speed.

### C7 — Future scarcity is not "humanities" or "science" but abstraction plus reality correction

**Article support:** `P8`, dependent on `C6`

Two complementary capacities are joined:

```text
high abstraction
+
continuous correction by external constraints
```

The article uses engineering/science as an example of reality enforcing constraints, while also noting that objectives, power, value and institutional definitions cannot simply be treated as fixed engineering inputs.

The desired capability moves between layers:

```text

energy / compute / API / supply chain / execution permission
```

### M4 — New evidence should cause recomputation, not narrative absorption

Instances:
