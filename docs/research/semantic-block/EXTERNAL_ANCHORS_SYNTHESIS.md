## Transfer conclusion

The common methodological lesson is **separate local semantic content, cross-context linking, and higher-level composition**, while keeping source spans and perspective attached to each claim. For LCE this supports a *single public SemanticBlock* with readable canonical meaning and minimal typed fields, an internal compiler/linker, and a graph index that consumes admitted blocks and later structures. It does **not** prove that this representation is sufficient. [The block benchmark](BENCHMARK_SPEC.md) must falsify or support that hypothesis before any production compiler work.

The external studies answer different questions: GraphRAG evaluates corpus-level question answering, AMR/UMR and PDTB/TimeML design annotation languages, and FactBank describes source-relative factuality. Their datasets and metrics cannot be added to the small LCE synthetic fixture scores as if they were one replication.
