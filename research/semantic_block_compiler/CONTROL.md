# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：在截止时点内，将 Body 真正理解的语义忠实、非排他地编译为自包含 SemanticBlock；同一来源可支持多个 Block，多个来源可共同支撑一个 Block，未知可以保持未知并待新证据重解释；不为 Embedding / Path B / Line 牺牲语义。

**当前 Hypothesis**：A 阶段给出的 `depends_on` 并不天然等同于「两个 cognition 必须属于同一个 Block」。语义支持、解释所需背景、认知演化关系、共同指代、共同主题与「必须编译为同一个完整认知」可能不等价。连通分量只保证连接性，无法自行判定必要语义边界；这是待证伪的假设，不是新的形式化定论。

**已证伪／不得复跑**：
- 排他切分、以 Block / Line 数量评判语义忠实；
- 用弱模型能力、Embedding、Path B 评价强 Body 的编译方法；
- 增加自由改写、阶段/审查器天然避免信息损失；
- 「A 理解条目多于 B Block 数」等于丢失：E1 已观察到合法多对一、历史已存的反例；
- 追加查漏能自动修正旧 Block 的错误内容或错误合并：E2 有反例；
- A→B 完整传递即可证明边界正确：E3 中 74/74 完全复现，但错误依赖注入仍改变分组；
- 他人研究已有可直接照搬的正确认知编译算法：目前无证据。

**完成实验 E1 / E2 / E3**：
- E1 冻结 33 步回执复放，定位理解层、交接层与准入层故障，并区别合法合并：[GitHub #37751393698](https://github.com/Jasonatafricanow/LCE-Longitudinal-Cognition-Engine/actions/runs/37751393698)。
- E2 真实历史日记 6 个截止时点，GPT-6 手工首轮 22 Block；追加查漏发现 4 个可溯源候选及 4 处不能靠追加修复的问题；非独立盲评。
- E3 只读 Astra 4 个重叠窗口：A 为 81 个 cognition、B 为 74 Block。无需再次调用强模型，仅凭 `depends_on` 连通分量及逐字载荷即可逐字段复现 74/74。注入错误依赖或移除真依赖后内容仍全保留，边界却改变。**这是交付复现，不是认知边界认证。**

**下一项有信息增益的唯一实验（待满足条件）**：为一个从未进入 E1/E2/E3 的连续真实对话窗口分别冻结 (1) Body 强模型的完整 cognition + 来源 + `depends_on` 输出，(2) 与 (1) 不互见的独立依赖/自包含边界标注。比较两个边集合的必要性、漏连、错误跨主题连边，以及连通分量组是否真正满足 Block 自包含与独立召回；允许重叠支持而非强制唯一划分。记录分歧原文及其 cutoff，采用事先固定的判准，不以节点数评分。输入 / 输出均应留存可审计回执但不公开用户原始私有对话。

**Why information gain**：它能区分「A 的语义依赖判断错误」和「`depends_on` 判断正确，但用无向连通分量当作 Block 边界的规则错误」。这正是 E3 的完美内容守恒所无法判明的两种解释。

**Stop Condition**：E4 由于缺乏独立强 Body A + 盲标而在准入处停，禁止退回已有 Astra 窗口、Qwen3B、人工自己写 gold 自己评或再次跑 Embedding/Path B。只有独立输入和评审结果两者可用后才能执行 E4；实验结束仍只更新本控制面。
