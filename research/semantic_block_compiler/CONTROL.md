# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：把 Body 在给定 `known_at` 的实际理解忠实、非排他地编译为最小且可独立重建的 SemanticBlock。允许同源多认知、跨证据支持、局部未知和新证据下的回顾性新解释。不能因 Embedding／Path B／Line 或块数量偏好删改认知。权威定义：`docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md`。

**当前假设**：`depends_on` 的方向性支持关系不足以直接定义 Block 身份。M3 直接对依赖求无向连通分量，有跨主题、跨纠正阶段的传递扩张风险；M4 将独立认知保留为 primary，再附有限支持，可避免身份合并，但必须判定**哪些背景是自包含所必需的**，否则独立载荷可能不完整或支持复制过多。二者均未获得独立的源语义忠实性与最小性认证；E10 只在冻结 A 上构造并比较具体产物。

**已证伪／不得复跑**：排他切分、以 Block/Line 数或弱模型能力排名代替语义质量；以 Embedding/Path B 回推编译；自由改写或审查必然无损；A→B 全字段守恒即语义边界正确；认知条数不同即遗漏；把独立模型盲标当人工 gold 或将 PARTIAL 改成等价；将合法回顾性新证据统称时间泄露；只根据复述原有 primary 断言重建成功；按支持条数匹配便称公平语义负对照。

**冻结研究链**：E1 定位理解／交接／准入损失；E2 追加查漏仅有局部候选收益；E3 Astra 81 cognition→74 Block 的 B 输出可由冻结 A 连通分量复现；E4 独立强 Body（38 cognition／58 依赖）与盲标（17 cognition）严格只对齐 3 对，依赖准确率 INCONCLUSIVE；E5 四组 PARTIAL 候选边界都落入 32 项大分量；E6 保留依赖同时分开主认知是构造可行而非正确性认证；E7 校正 AS_OF 与 RETROSPECTIVE，E8 对照输入修订，E9 证明旧重建评审会被复制 primary 的零模型基线绕过，尚无独立语义裁决。

**E10：同源候选编译器产物的直接比较（2026-10-08，完成）**：
- 对 E4 冻结的 10 条真实消息、38 条 Body cognition 和 58 条原始依赖读取并验证哈希；不重新生成强模型输出、不调用弱模型、不变更语料或真实关系。
- **M3** 复用 E4 原版组件：4 个 Block，大小 `[32,4,1,1]`；最大的 `CC2` 跨 6 个来源消息，混合用户与助手认知。内容/来源单元均仍保存，不能把多认知分块少直接称为信息丢失。
- **M4 构造候选**：38 个各有独立 primary 的候选 Block，沿用 E6 冻结的 8 个目标有限支持，其余仅按冻结图附加直接支持（这 30 个的支持必要性**未经检验**）；整体保留 38/38 primary 原文、58/58 原始依赖，支持正文共复制 59 份。
- 四组原先盲标提出的 `must_separate` 候选在 M3 中全部落入 `CC2` 且两端无直接依赖边，M4 中可分别索引：`A6/A7`、`A15/A17`、`A10/A28`、`A11/A32`。但这些盲标及 PARTIAL 映射不是经认证的语义真值，不报告 M3 错误率或 M4 准确率。
- **M4 失败边界的来源见证**：A7 裸载荷只说“后来用户作澄清”，并未写出澄清内容。原始 `R399443` 明确“是我要回家…我现在还在办公室”，而 `A25` 载荷有该内容。E6 选择 `A25` 支持 `A7`，且 A7 自身无 outgoing `depends_on`，A25 反而指向 A7；说明一个裸独立载荷和仅沿 outgoing 边补全都可能遗漏回顾性完整意义。该局部字面见证不等于全局盲评分。
- **代价**：M3/M4 共同的唯一 primary 正文为 2,065 字符，若 M4 逐 Block 物理复制全部 59 份支持正文，则额外 2,929 字符，总计为唯一正文的 **2.418 倍**；共享存储可去除物理冗余，但提供给读者的 Block 仍须足以重建目标意义。非通用性能基准。
- 合成增加 `A1—A6` 一条跨分量边会让 M3 从 `[32,4,1,1]` 变成 `[36,1,1]`，M4 仍保持 38 个 primary 身份；**这是注入测试，不是实际 Body 产错边的证据**。

**唯一下一实验及信息增益**：针对 `A7 ↔ A25` 这个已经有源材料见证的最小边界，冻结两种**完整语义载荷**：单独 A7、A7＋精确必要的澄清支持，不加入额外话题；让隔离于现有输出的重建者在不见原文时复述；另一位独立原文裁决者按同一 RETROSPECTIVE 截止判断是否准确恢复“待回家者是谁、什么时候明确、归属是谁”。两方评分分别冻结，验证 **正向依赖边能否充分找到必须的支持**，而非第三次再测连通分量大小。之后才考虑扩大到其他 3 组；允许共享支持，但不可把真实历史状态覆盖为未来已知。没有独立评审回执就不能宣称最小自包含算法胜出。

**Stop Condition**：E10 的两份同源候选产物、哈希与结构性反例复现已完成，立即停止扩大评测；独立源级语义裁决尚不存在，**M3/M4 优劣仍为 INCONCLUSIVE**。不能以 38 个独立 Block 数更大就认定质量好，不能把支持文字更多当成功。生产代码未修改；本轮只回写这份控制面。
