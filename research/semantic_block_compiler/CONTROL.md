# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：在证据截止时点，忠实、非排他地将 Body 的认知编译成最小、自包含的 SemanticBlock；同源多 Block、跨证据、局部未知及后续新解释均合法。以 `docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md` 为语义权威，不为 Embedding／Path B／Line 损失语义。

**当前 Hypothesis**：`depends_on` 描述方向性的背景／指代／解释／纠正关联，不自动表示 Block 身份等价。形成自包含 Block 需要有限而**截止安全**的上下文；简单切开载荷或整个连通分量打包都有风险。E7 已发现 E6 中一次真实的后见信息回填，故必须将 `known_at` 约束放在重建实验判准中；这不是宣布正确分组算法。

**已证伪或必须拒绝的捷径**：
- 排他切分、按 Block/Line 数量判断语义质量、拿弱模型排名或 Embedding／Path B 回推编译。
- 多阶段 Prompt／自由改写／额外审查必然无损；A→B 字段守恒即可证明边界正确；认知条数与 Block 数不同即代表损失。
- 将独立模型输出当人工真值、将 PARTIAL 标为等价、用跨时点完整叙事迫使历史 cognition 共用身份。
- “只保留全部依赖边”足以证明一个独立载荷的语义自包含：E6 并未做隐藏原文重建认证。

**证据链（冻结，不重跑）**：E1 定位理解／交付／准入损失；E2 定向查漏能补候选但不能修旧错误；E3 Astra 81 cognition→74 Block 的第二阶段被确定性分组完全复现；E4 独立 Body 38 cognition、58 依赖，对照盲标 17 cognition，只严格对齐 3 对，结果 INCONCLUSIVE；E5 四项 PARTIAL 分离约束落入 32 cognition 大连通分量，但未认证为真值；E6 保留 58 关系并分开四组载荷的构造可行，但未做自包含重建评审。

**E7 截止安全与隐藏原文评审准入检查（2026-10-08；已完成）**：
- 使用 E4 原始输入 SHA256 锁定 Body、blind、raw，沿用 E6 四组目标（8 cognition）；生成 **32 个随机顺序的评审包**，每个目标四条件：isolated、E6 原始 scoped、**按截止过滤的 scoped**、完整终局 component。后两种不等价：原版 scoped 与大 component 是带已知风险的负对照。评审包不含 Raw Evidence，封存的 ID→条件映射与之分离。
- **已确认 E6 的时间泄漏**：目标 `A10` 截止于 `2026-09-30T07:23:43Z`，原配背景 `A7` 的认知依据最晚到 `07:25:06Z`，即较晚的用户澄清。故 `A10←A7` 的反事实支持不满足截止安全；截止安全包已排除这一支持。

**唯一下一实验为何有信息增益**：让**未见原文、未见条件映射、未见旧 E4/E5 评分**的独立评审在隔离会话逐包重建，先封存答案，再由另一个证据裁决步骤以各目标的合法截止时点核对。仅以 `isolated` vs `scoped_cutoff_safe` 作可比较的候选机制，原始 scoped／终局 component 为有毒性控制。观察它们是否改善归属、未知、因果条件和纠正意义，是否带来推断污染，以及哪些认知必须真正并入同一最小 Block。这能区分背景不足、边界必要性和后见泄漏；现有字面探针无法替代此实验。

**Stop Condition**：E7 预检已找到具体时间泄漏、生成封存评审任务并验证源完整性，**在尚无独立重建结果时停止**；不计算 semantic precision，不宣布新编译算法通过，不让当前助手读了原文后自行伪装盲评，不追加模型、语料或 IR 大设计。评审回执未到之前不启动下一轮。每轮结束仍只更新这份控制面。
