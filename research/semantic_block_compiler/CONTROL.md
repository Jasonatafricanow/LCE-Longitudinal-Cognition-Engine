# SemanticBlock 编译研究｜唯一控制面

## 冻结 Objective（不可随实验改写）
通过多组不同类型的真实/受控语料做逆向工程，发现能够**稳定编译语义、形成供 LCE 向量模型组织的结构化材料**的因子与算法；由 LCE 向量组织得到候选结构，再由 LLM 消费、判定是否存在真实关联、重复模式或趋势。先固定实验 Block，等内容编译规则稳定之后才研究如何切分 Block。权威语义边界仍见 `docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md`；实验阶段的固定 Block 容器**不是最终产品的 Block 切分方案**。

**语义保真判准（2026-10-09 用户澄清；实验必须执行）**：追求**功能性语义等价／可大致恢复原意**，不是忠实复述原文、保持原文字数、句式、用词或非关键细节。允许摘要、改写、语序变化、必要消歧及去冗余；只要接收者在看不到原始对话时，能从编译载荷恢复关键理解即可。不得改变会使原意走样的内容（例如是谁说的、确认程度、否定、前提、承诺与时间状态），也不能凭空制造新认知。来源原文逐字锚点仅供溯源核对，**不是**编译质量指标；长度匹配仅在确有必要隔离实验变量时作辅助控制，**不是**语义保真目标。实验中应以不看原文的 LLM 恢复意思、再对照原文检查是否有实质歧义为判断方式之一，不能用词面重合率／精确复述替代。该判准贯穿三步，但不新增一套前置评估工程。


## 冻结研究路线：三步，严格顺序

### STEP 1 — 固定 Block，逆向研究**内容编译**
- 取几组语义环境不同的语料，冻结各样本的原文、上下文范围、时间截点、**实验 Block 边界**；各候选编译方案使用相同输入和固定边界。
- 先实际编译：可从原文直写、自由语义编译、少量可操作语义因子（例如来源归属、条件、否定、未知等）对照起步；因子应由失败/收益反推，不先假定字段全集或最终 IR，不在此时研究自动切分。
- 输出可被 LCE 嵌入/组织的语义结构或可序列化载荷，保存原文、编译版本、因素变化与来源见证。只要求避免显见捏造/关键原意丢失，**不以产品级噪音率、向量本身懂逻辑或最终检索名次作开工前提**。
- **STEP 1 交付门槛**：至少在不同语料环境生成可比较的固定边界编译产物，并标明待观察的因子；此时还不称其为“稳定算法”。不能以流程稿、规则清单或修补执行器代替编译输出。

### STEP 2 — LCE 向量模型组织**候选结构**
- 用**固定的同一 LCE 向量模型、参数和语料集合**处理 STEP 1 各种编译产物，观察相邻、聚类、局部连接、可能趋势或重复模式等候选结构及其变化；记录什么编译因子导致结构信号出现、消失、稳定或改变。
- **向量组织不是语义裁判**：不要求它判因果、转述、否定或逻辑真假，更不因模态相近/遥远直接判编译正确。此步得到的只是给 LLM 消费的候选。
- **STEP 2 交付门槛**：真实的向量组织产物及可追溯的编译版本对照；没有真实 LCE 模型产物就报告阻塞，不得拿模拟向量充数。

### STEP 3 — LLM 消费结构，检验**是否发现有效关系**
- 给 LLM 看 STEP 2 的候选结构及适当的编译材料，判断是否存在实际关联、重复模式、演化或趋势，明确区分“结构提示”与“LLM 采纳/拒绝的关联”。
- 回看不同语料与不同环境结果，做因子增删/消融/迁移，逆向收敛能**大致稳定提供有用候选结构**的内容编译方法。初期先验证“能发出有用信号”；产品级误关联/噪音治理留待此后。
- **STEP 3 交付门槛**：LLM 的实际消费回执、具体成立/不成立的关系证据、编译因子的跨环境表现；不允许仅用向量命中分数代替 LLM 语义判断。

**独立的后续研究（暂锁）— Block 切分**：只有 STEP 1—3 的编译方法经过跨语料对照、获得基本稳定的组织及消费效果后，**固定该内容编译规则**，才开放 Block 粒度/边界变量，再按 STEP 2—3 观察不同切法。此前不研究 split/merge、`depends_on` 连通分量、语义闭包、图优化。
