# SemanticBlock 编译研究 | 唯一控制面

**Objective**：在截止时点内，忠实、非排他地将 Body 已理解的语义交付为自包含 SemanticBlock；多 Block／跨证据／暂不理解和后续重新解释均允许；不利用下游结构奖励删减。

**当前假设 H**：真实故障至少有两处——已识别认知在理解→Block 交接时被静默遗漏，以及理解清单本身就发生错误合并。必须把这两类和合法多对一合成区分开。

**已排除／不再重复**：
- 排他性切分与以 Block/Line 数量评优不适用；
- 用 Embedding 或 Path B 调参替代语义编译；
- 用固定弱模型证明编译算法优劣；
- 增加提示词阶段或审查器会自动保障无损：现有回执已出现反例；
- 外部研究有可直接照搬的无损语义编译器：缺少证据。

**唯一下一实验 E1**：对 2026-10-08 已冻结的 33 步原始推理回执进行只读远端重放，对比 naive 计数报警与按可追溯语义 witness 的逐项去向检查。检查 Stage A 已有而 B 丢失、Stage A 本身合并、B 合法合并、B 重复及独立审查误拒。阶段输出不重新生成、不换模型、不调用 Embedding/Path B。

**信息增益**：如果计数法把合法合并当损失，或不能指出源头错误，而逐项去向检查能区分，则明确问题是「认知是否被追踪」，而不是输出条数；如果无法区分，则不应继续投资这条方向。

**Stop condition**：当 E1 能定位理解层／交付层／准入层的可复现实例并区分合法合并，立刻停；若只是再次展示弱模型错误而没有新增定位能力，也停。结束后只更新本文件的结论与下一实验状态，不产新设计报告。
