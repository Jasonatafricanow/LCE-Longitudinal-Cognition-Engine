# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：将 Body 在给定认知时点真正理解的内容忠实、非排他地编译为最小、自包含 SemanticBlock；允许跨证据、局部未知与事后新解释，但新解释的 `known_at` 不得伪装成旧时间点。不得为下游图、召回或 Block 数量牺牲语义。权威定义：`docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md`。

**当前 Hypothesis**：`depends_on` 是方向性的背景／指代／纠正支持，不自动等于同一 Block 身份。要证明有限背景对**目标意义**有增益，必须与等信息数量的非定向背景对照，并判断额外背景有没有被错误吸收进目标认知；不能只证明给模型更多文本能回答更多问题。在线 AS_OF 与事后 RETROSPECTIVE 需分开解释，允许后者使用后续证据。

**已证伪或不得再用的推断**：排他性语义分割；以 Block/Line 数量、弱模型排名、Embedding/Path B 评价编译；Prompt 阶段或字段守恒即能保证认知忠实；把 PARTIAL 变成 EQUIVALENT；把独立模型输出视作真值；把合法回顾性新理解称为时间泄露；通过针对额外背景专门设计的问答，宣称证明“背景必须与目标合为一个 Block”。

**证据进度**：
- E1：冻结回执定位理解／交付／准入三类损失；E2：追加查漏仅能补候选，不修复旧误合并。
- E3：Astra 81 cognition→74 Block 的第二阶段可由冻结 A 确定性复现；未认证 A 的语义边界。
- E4：两份独立强模型输出，38 cognition／58 边 vs 17 cognition／盲标；仅 3 对完整可比，正式结果 INCONCLUSIVE。
- E5：四组 PARTIAL 边界冲突候选均落入同一个 32 cognition 连通分量；E6：关系边可以原样保留而载荷分开，但未证明载荷自包含。
- E7：8 目标×4 条件，32 个盲评输入；早期报告将回顾性证据一概判为时间污染的说法已撤回。仅完成字面线索探针，未执行独立语义重建。

**E8：冻结评估工具有效性审计及修订（2026-10-08，完成预检，未运行独立模型）**：
- 对 E7 全部 32 包及密封映射执行确定性重算：8 个目标中 **7 个** `scoped_original` 与 `scoped_cutoff_safe` 的实际支持文本完全相同；**1 个** `isolated` 与 `scoped_cutoff_safe` 完全相同；32 包均未显式保存认知生成时间 `known_at`。问题固定针对各目标的补充线索，而 9 项 E7 字面探针中已有 6 项仅在支持材料出现——因此旧问答增益不能认证独立 Block 的最小性。这是评估设计诊断，非语义准确率结果。
- 只使用同一 E7 冻结材料，生成 **24 个匿名输入**：8 个目标分别为 isolated／focused_cutoff_safe／shuffled_unselected，评审统一使用与目标无关的语义重建指令，明确需剔除与 primary 无关的额外背景。7 个目标的 focused 与 shuffled **支持条数匹配**；A6 的 focused=0，额外加入两项 unselected 支持作为干扰注入哨兵，**不纳入条数匹配比较**。Shuffled 来自同一冻结认知池，**未经独立验证为无关文本**，字数和 token 预算也未精确匹配。
- 统一声明 RETROSPECTIVE（整段对话最终观察时点），不由来源的 `occurred_at` 猜测 `known_at`；评审输入与密封映射分离、只含模型认知陈述和来源元数据，不公开原始对话。无新模型推理、无生产代码改动，**不能报告语义评分**。私有审计 manifest SHA256：`4213049900011bd4fae08975407aee52db4188651596d9257d18f029c5829ed8`，盲评材料 SHA256：`f8610e7f95fbe3f5b12a837ec0ed9126bc3a72a7b204bdade689b4717bec76e4`。

**唯一下一实验为何有信息增益**：独立评审者各包隔离运行，不见原文、旧对齐和密封映射，先逐包冻结重建输出；独立原文裁决者再标注目标认知的归属/条件/未知/纠正是否丢失，以及背景是否被误合并。比较 isolated、focused 与未筛选同条数背景，测试“定向背景带来语义必要性”而不是“上下文多所以答得多”。不要把 shuffled 预先称为错误支持，也不要把这次回顾性测试用于在线时间评分。

**Stop Condition**：E8 的可辨识性问题已确认、修订输入及校验通过，立即停止。**目前没有独立重建与独立原文裁决回执**，不能判定哪种 Block 编译方法胜出或宣称必要依赖规则已建立。后续拿不到独立评审结果则继续停，不重新跑弱模型、扩大样本或设计新 IR。完成后仍仅回写这张控制面。
