# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：在截止时点内，将 Body 真正理解的语义忠实、非排他地编译为自包含 SemanticBlock；同一来源可支持多个 Block，多个来源可共同支撑一个 Block，未知可以保持未知并待新证据重解释；不为 Embedding / Path B / Line 牺牲语义。

**当前 Hypothesis**：`depends_on` 的方向性语义支持与「必须同属一个最小自包含 Block」不是同一判准。E5 已在真实冻结语料发现 4 项独立标注的 `must_separate` 候选边界均被 Body 的无向连通分量跨越；但只有 **PARTIAL 语义锚点** 而非完整 cognition 等价，尚不足认证 4 个 Block 边界错误。另一风险是盲标自身有原文不支持的推断，不能把独立模型输出当成人工 gold。

E4 已在另一真实会话的连续 10 条可见消息上完成本地独立输出与对照（2026-10-08；从远端 `33ba836` 同步后开始）。Body 为 Codex CLI `gpt-6.1-sol / high`：38 项 cognition、58 条依赖；原文盲标为 agy CLI `claude-opus-4-6-thinking`：17 项 cognition、24 条依赖判断、12 条边界约束。两方使用相同截止原文，在隔离的新会话中生成，盲标不见 Body 输出；两份输出先封存，再以屏蔽双方依赖及分组的独立调用做认知对齐。这是跨模型盲标，不是人工 gold，也不宣称严格未见。

**E4 结果：INCONCLUSIVE。** 按事先冻结的完整一对一对齐判准，仅 3 对认知可比，没有一条 Body 边的两个端点都进入可比集合，58 条边均为未决；不能报告依赖 precision，不能归因于 Body 依赖错误或连通分量规则错误。认知粒度、范围、归属和未决表达的差异必须保留，不能为获得分数强行对齐。以下「E4 准入审计」保留为本轮开工前的历史快照，其 0 份输出与未启动结论不代表当前进度。

**E5 冻结部分语义锚点审计（2026-10-08；探索性，完成并停止）**：
- 复用 E4 的原始会话、冻结 Body（38 cognition、58 directed dependencies）、盲标（17 cognition、12 boundary constraints）及独立对齐（仅 3 完整等价）；**没有新 LLM 调用、没有改写 PARTIAL 成 EQUIVALENT、没有修改两份原始判断**。
- 独立盲标约束为 `must_separate=4 / overlap_allowed=7 / must_together=1`。针对全部 4 个 `must_separate` 约束，采用**原文 source ID 与 PARTIAL 中共同的明确语义命题**作较弱的单向锚点，而不是要求完整 cognition 一对一相等：J3/J4→A6/A7、J10/J11→A15/A17、J6/J15→A10/A28、J7/J16→A11/A32。四对对应 A 均在同一 **32 项连通分量**，且每对没有直接依赖边，最短路径分别为 `A6-A8-A7`、`A15-A13-A17`、`A10-A7-A27-A28`、`A11-A6-A8-A32`。这些是**可能的最小边界冲突见证**，而非经认证的边界错误或 dependency precision。
- 对照证据：盲标 J8/J10 明确给出 `overlap_allowed`，Body A15→A13 给出方向性语义依赖；“解释需要某背景”不能逻辑推出“双方必须互为同一 Block 成员”。另一方面盲标 J12 无来源依据地增添了「用户在家等母亲」，显示独立参考也会犯归属和情境推断错误；不能直接将它作为最终语义真值。
- **E4 的 58 条依赖仍全部是正式评估中的 UNRESOLVED**；E5 没有把这四项计入错误率，也没有证明那 32 项应当怎样正确分组。四条约束来自同一段对话，具有相关性；映射是在既有输出冻结后作的探索性证据选择，非预注册独立盲测。研究脚本和非原文回执留在本地（E5 回执 SHA256 `da86ae0e7c76e457a7cb4f0cbf9236f2d7a926eddce5f98033e44b506ed5cc7c`），不把私有原文上传公开仓库。

**E5 为什么有信息增益**：E4 的严格全等端点规则导致 58 条依赖全数无法评分；E5 证明可以在不篡改 PARTIAL 标签的前提下找到**由原文锚定的、可指向具体图路径的边界冲突候选**。它将下一轮问题收紧为「什么样的部分语义见证足以裁决 Block 最小性」和「独立盲标本身的真实性如何审定」，而非一味增加模型或样本数量。对“依赖关系正确 vs 连通分量规则错误”的最终归因仍未获得。

**已证伪／不得复跑**：
- 排他切分、以 Block / Line 数量评判语义忠实；
- 用弱模型能力、Embedding、Path B 评价强 Body 的编译方法；
- 增加自由改写、阶段/审查器天然避免信息损失；
- 「A 理解条目多于 B Block 数」等于丢失：E1 已观察到合法多对一、历史已存的反例；
- 追加查漏能自动修正旧 Block 的错误内容或错误合并：E2 有反例；
- A→B 完整传递即可证明边界正确：E3 中 74/74 完全复现，但错误依赖注入仍改变分组；
- 他人研究已有可直接照搬的正确认知编译算法：目前无证据。
