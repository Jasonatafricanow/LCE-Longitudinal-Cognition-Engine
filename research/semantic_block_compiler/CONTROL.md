# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：忠实、非排他地把 Body 在各截止时点真正理解的认知交付为自包含 SemanticBlock；支持同源多 Block、跨证据闭包、保留暂不能解释的原始依据，以及新证据下的新解释。不要以上游删改迎合 Embedding／Path B／Line。

**当前假设**：编译故障至少跨理解、认知身份/边界、内容交付、来源归属和准入；GraphRAG 式追加查漏有机会补回静默遗漏，但不能仅靠追加新 Block 修复已经写入的误合并、约束弱化或上下文越界。需用独立强模型输出和不见输出的语义裁决评估净增益，不能继续靠同一助手人工复述证明。

**已否定／避免重跑**：
- 排他分割；用 Block 数／Line 数表示语义质量；拿 Embedding／Path B 调参替代上游研究。
- 固定 3B 弱模型的错误足以证伪 Body 编译；增加 Prompt 阶段／审查器必然无损。
- 单纯拿「理解条数 > Block 条数」报警：E1 中每种分阶段方法 8 个报警点仅 3 个截止时点发生经语义 witness 核对的遗漏（2 项不同认知），其余包含合法合并／历史已存。
- 把追加补全视作完整修复：E2 已出现不能靠新增认知消除的原稿错误。
- 假定外部研究已给出可直接照搬的正确认知编译器：没有得到证据支持。

**已完成 E1：断点定位**。只读远端复放既有 33 个回执，辨别理解层合并、理解→Note 遗漏、准入误拒与合法多对一。控制条件 S1 已达成：[运行 #37751393698](https://github.com/Jasonatafricanow/LCE-Longitudinal-Cognition-Engine/actions/runs/37751393698)。

**已完成 E2：追加式查漏候选（2026-10-08）**。另取历史日记真实语料 2 段连续事件、合计 6 个截止时点；由本会话 GPT-6 手工直接编译并冻结 22 个 Block（SHA256 aa854db11c5b1c7de962a8f5742a3c3fb4b77c3df043f2797df5a434ea143c6e），再按仅查漏规则提出 4 个原文可定位的新候选，检查其可见来源和 cutoff；同时发现 4 条不能直接追加解决的问题（约束弱化、可能错误合并、正文不充分、被截断的上文）。原始私有对话与各阶段 JSON 仅在会话工作目录，不向公开 GitHub 上传。

**E2 的信息增益及局限**：证明“在固定第一稿后，第二次定向检查能找出额外可溯源的候选”在这批语料中确实发生，且揭示了“新增覆盖”与“修复既有错误”不同；但 **不是** 可靠的增益率/准确率，更不证明生产算法有效：同一 GPT-6 完成两遍并自行判断，无盲评、无独立 gold、无随机化、无推理预算公平对照；原始日记档案过去曾被用于其他研究，也不是全球未见过的语料。此前旧版评估目标只用于事后辅助对照，未覆盖全部认知。

**下一候选 E3（准入尚不满足，暂不开工）**：只有获得独立的强 Body 自动推理通道 + 与模型输出隔离的第三方语义标注，并冻结真正不与旧例重复的原始对话，才比较同强模型的直接编译 vs 同编译后 GraphRAG 式追加查漏；逐项标注原文支持、非排他性、遗漏、误增、误合并、未决、来源、历史已存与计算成本。对照必须区分新增的有效认知和新增的伪造/重复。如果这两个前提拿不到，不再运行伪对照。

**Stop Condition**：E2 已停止；今轮只更新此控制面。若下轮拿不到足以排除“同模型自我检查/人工裁决偏差”的独立证据，就停，不得替换成强弱模型排名、架构设计或向量调参。
