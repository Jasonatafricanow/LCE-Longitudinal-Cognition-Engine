# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：将 Body 在给定认知时点真正理解的内容忠实、非排他地编译为最小、自包含 SemanticBlock；允许跨证据、局部未知、后验重新理解，且 `known_at` 不得伪装成更早时点。不为 Embedding、Path B 或 Block 数量牺牲语义。定义以 `docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md` 为准。

**当前假设**：`depends_on` 描述背景／解释／指代／纠正关系，不天然等于 Block 的同一身份。M3（依赖连通分量）可能过度合并；M4（独立认知＋必要共享支持）可能保留粒度，但其自包含性和额外支持的语义必要性尚无独立认证。评估须区分 **已有认知的复述** 与 **原文语义是否被真实保留**。

**已证伪／不得复跑**：排他切分；按 Block/Line 数量或弱模型能力评分；用 Embedding/Path B 反推编译；自由改写或审查天然无损；A→B 字段守恒即可认证语义；把 PARTIAL 对齐变成等价；把独立模型盲标视为人工 gold；把回顾性合法后见理解统称时间泄露；仅凭支持条数匹配或重建文本丰富程度就认定上下文必要。

**冻结证据**：E1 定位理解/交接/准入故障；E2 追加补全带来局部候选但未纠错；E3 Astra A 81 项认知→B 74 Block 可确定性复现；E4 两份独立语义输出仅 3 项完整对齐，58 条依赖不能裁决（INCONCLUSIVE）；E5 四个 PARTIAL 边界冲突候选；E6 在保留全部关系时可构造分离载荷（自包含未认证）；E7 时间结论已按 AS_OF 与 RETROSPECTIVE 校正；E8 对原八目标制作 24 个匿名背景对照输入，但未运行独立语义裁决。

**E9（2026-10-08；冻结 E8 输入的零模型反事实核验，完成）**：
- 经 SHA256 校验的原 E8 **24 个包仅包含 8 种不同 `primary`**；同一目标的三条件 `primary`、来源及状态完全相同。仅复制 `primary.statement`、忽略全部 `support`，就能输出 **24/24 份结构合法、每目标三条件完全一致**的机械基线；这并非语义正确率，也非有效的编译器，只证明“复述式输出”可以绕过弱的重建形式检查。
- “定向”支持 **10/10 均为冻结 Body `depends_on` 图中的一跳节点**，由待验证关系自行选取，非独立语义必要性 gold。“未筛选”支持 **2/12 也是一跳 Body 依赖**（A32、A6 两包）；故它不是认证的无关负对照。这些一跳关系也是 Body 主张，非真值。
- 7 个条数匹配目标的聚合背景字符数：focused=504、unselected=597；只匹配条数，未匹配字符/token 长度。语义重建模型尚未执行，**没有 M3/M4 净效果结果**。
- 不修改 E4 Body、E8 评审包或任何生产代码。实验回执 SHA256 `5e0b3e40adaf16308ef315cf80f8d3b41042bbe4b552330dfb2fb26c84967ad2`；私有语料和映射仅留本地。

**唯一下一实验为何有信息增益**：针对 E4 已冻结的四组边界冲突，生成 M3 大连通分量和 M4 独立载荷＋有限支持两种同源编译结果；随机盲交给**看不到原文、也看不到机制标签**的独立重建者，冻结回答后再由**可见原文、看不到机制标签**的独立证据裁决者评估两种产物的归属、模态、未知、纠正、跨时点权威、遗漏、误增和独立可召回性。必须允许多对多语义支持，不能以“新文更长／语义条数更多”为优。**关键区别**：在裁决时检验源证据真值，不拿 `primary` 本身作答案；预先固定目标与 adjudication 判准。当前未取得独立双重评审回执，不提前报告结果。

**Stop Condition**：E9 的零模型基线与对照污染检测已复算通过，停止继续修 E8 问卷或扩大弱模型测试。没有独立、与结果隔离的源级语义裁决时，不将 E8 当成可比较的机制胜负评测，不自行生成 gold 或宣称 M4 优于 M3。仅更新本控制面，不动生产代码。
