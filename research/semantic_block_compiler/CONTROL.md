# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：忠实、非排他地把 Body 在截止时点真正理解的认知交付为自包含 SemanticBlock；允许同证据多 Block、跨证据闭包、暂不可知信息保留、后续重新理解。不为 Embedding／Path B／Line 减删语义。

**当前假设**：认知发现和必要语义依赖判断主要发生在 Body 理解阶段 A；对 Astra 所用「B 逐字保留 A 的 statement、status、evidence、depends_on」协议，额外调用强模型 B 可能没有可观察的附加价值。**这不是断言语义编译已解决**：A 是否发现全部独立认知、依赖是否真正「必需」、Block 边界是否完整，尚未获得独立认证。

**已排除／避免重跑**：
- 排他分割，或用 Block/Line 数量替代语义忠实度。
- 用弱模型错误、Embedding、Path B 来判定强 Body 的编译能力。
- 增加自由改写、分阶段 Prompt 或审查器会自动消除信息损失：已有反例。
- 用「理解条目数 > Block 数」直接报警：E1 假阳性包括合法合并、历史已存。
- 把追加查漏当成旧认知纠错：E2 发现原稿的约束弱化与错误合并未被追加解决。
- 把 B 原文守恒视为语义正确：A 的错误依赖、错误边界能够完整穿过 B。

**E1 断点定位（完成）**：只读远端重放既有 33 步回执，区别理解层合并、理解→Block 遗漏、准入误拒、合法合并；[Actions #37751393698](https://github.com/Jasonatafricanow/LCE-Longitudinal-Cognition-Engine/actions/runs/37751393698)。

**E2 追加查漏（完成，证据有限）**：6 个历史截止时点、GPT-6 手工首稿 22 Block；二次检查多提出 4 项原文可定位的认知候选，但存在不能靠新增 Block 修复的旧错误。非独立盲测，不计准确率。

**E3 Astra 原生 B 的附加贡献（完成，2026-10-08）**：
- 冻结 Astra 提供的 4 个真实重叠窗口、81 项 A 认知、74 个强模型 B Block。只读本地实验；不重新推理/不更换模型/不公开上传私有原文。
- 用 A 的 `depends_on` 无向连通分量组 Block，`statement` 作逐字 predicate，`status` 及来源索引按 A 保留。**不调用 LLM，逐字段复现 74/74 个真实 B Block**（组成员、内容、units、qualifiers、unit_sources 均一致）；四个窗口独立结果分别为 21/21、10/10、15/15、28/28。
- Astra 强模型 B 四次调用历史用时合计 **346.59 s**；确定性投影无该模型调用成本（不能直接把时间差当通用性能基准）。
- 故障注入：在 shared 案例移除已有真实 `U6→U3` 依赖，Block 从 21→22；把无关的充值询问 `U14` 错连到状态纠正 `U3`，Block 从 21→20；两次 **22 项认知都仍保留**。这说明内容守恒检测无法辨别分组是否违反语义边界。注入仅为合成负对照，并非 Astra 自发错误。
- 限制：这些是重叠窗口，不是 74 个独立例子；证据不能证明连通分量适合所有语义依赖，也未认证 A 的语义准确、依赖关系、增量演化。私有上传资料仍限于当前会话。复算脚本 SHA256 `e7804b1930ba0798c5f05bdd39a72b5dda321ef00249bc468aec838b93905e0f`；回执 SHA256 `e93da7569da8d7d24a72b2a77ea1f6d2406184bad707bc9c42e0481740005356`。

**本轮信息增益**：在给定 Astra 冻结 A 和编译协议下，证伪「额外强模型 B 的这 74 个输出无法由确定性打包复现」；真正的语义判断与风险集中在 A 的认知身份/依赖和证据忠实性，B 的完美拷贝不能证明 Block 边界有效。

**唯一下一候选实验（尚未满足准入）**：抽取不与上述同一会话重叠的真实截止窗口；冻结强 Body 的 A 结果；对 `depends_on` 的**必要语义依赖**与 Block 自包含边界做独立盲标，不让标注者看到模型给出的边；比较连通分量分组与独立标注，并专门检查跨主题错误连接和必要关系漏连。要先有明确可裁决的标注和非重复输入；否则不开工，也不退回弱模型排名／补 Prompt。
