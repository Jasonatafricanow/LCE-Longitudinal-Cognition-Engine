# SemanticBlock 编译研究｜唯一控制面

**唯一 Objective**：忠实、非排他地将 Body 的理解编译成最小、自包含 SemanticBlock，保留语义来源、局部未知与双时间轴；支持事后新证据对旧证据的重新理解及新解释。不能将晚形成的认知伪装为历史时点已知，也不能为 Embedding／Path B／Line 丢弃语义。以 `docs/architecture/SEMANTIC_BLOCK_DESIGN_FREEZE_2026-09-25.md` 为权威。

**当前假设**：`depends_on` 是方向性的背景／指代／解释／纠正关联，不自动等于 Block 身份等价。应分别测试 **AS_OF(t1)：模拟当时在线可知内容**，以及 **RETROSPECTIVE(t2)：使用后来证据重新理解 t1 原始事件**。后者允许 t2 的证据参与认知，但新解释的 `known_at` 不得伪装为 t1；`occurred_at` 可以仍指向 t1。两种任务不可混用同一「未来信息泄露」评分。

**已证伪／禁止走回头路**：排他切分；以 Block／Line 个数或弱模型能力代替语义质量；Embedding／Path B 倒推编译；Prompt／自审必然无损；A→B 字段全保留就等于边界正确；以独立模型盲标直接充当 gold；把 PARTIAL 误标为完整等价；**把回顾性编译合法使用后来证据一概定义为时间泄露**。

**历史实验**：E1 找到理解→交付→准入损失；E2 追加查漏有局部候选收益而不能修正旧错；E3 Astra 81 cognition→74 Block 可由冻结 A 的依赖结构确定性复现，不能认证语义边界；E4 独立 Body 38 cognition／58 依赖与独立 blind 17 cognition 只严格对齐 3 对，INCONCLUSIVE；E5 四组 PARTIAL must_separate 候选均落入 32 cognition 连通分量；E6 保留全部依赖但分开四组目标载荷，未认证自包含性。

**E7 已完成预检（2026-10-08，独立重建仍未执行）**：
- 已封存四组共 8 项目标的 32 个随机盲评包，包含 isolated、原始 scoped、as-of 截止 scoped、完整终局 component 四个条件。9 项字面线索探针：isolated 3/9，其他三种各 9/9；这不是语义重建得分。
- 原 E7 把 `A10←A7` 作为 **“确认时间泄露”** 是错误定性。A10 的原始事件截至 `2026-09-30T07:23:43Z`，A7 引用了 `07:25:06Z` 才有的澄清：**仅当任务是 AS_OF(07:23:43) 时**，这种支持不可作为当时在线已知内容；当任务是 07:25:06 之后的 RETROSPECTIVE 编译时，使用 A7 是合法且可能必要的，必须区分新解释的 `known_at` 与事件 `occurred_at`。

**下一实验为何有信息增益**：在任何独立重建前，先**声明评估模式**，按 AS_OF 与 RETROSPECTIVE 分别审查现有四条件；若做回顾性重建，则保留后续证据、正确标注 `known_at`，不把后见理解判成污染；若做在线快照测试，则以对应时点过滤。独立评审需隐藏原文和条件映射，判断自包含、归属、未知、纠正语义以及过度合并，而不是按是否出现晚来源直接打分。两种模式的比较需要各自一致的时间定义；不额外跑模型补“时间泄漏”案例。

**Stop Condition**：先纠正 E7 将合法后见编译误判为泄露的研究结论；研究包与数据保持冻结。独立重建评审回执未到前停止，不能把字面可见性当语义准确率，也不宣称找到正确最小边界算法。每轮只更新本唯一控制面。
