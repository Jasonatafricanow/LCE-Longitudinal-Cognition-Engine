# SemanticBlock 编译研究 | 唯一控制面

**唯一 Objective**：忠实、非排他地把 Body 在截止时点已理解的语义交付为自包含 SemanticBlock；允许同源多 Block、跨来源、暂不理解与新证据重新解释。不以上游删减迎合下游 Line。

**当前假设**：至少三个不同断点并存：①理解阶段漏掉独立认知身份／未决状态；②理解清单已包含认知，但 Block 输出静默遗漏；③最终准入可能误拒。合法多对一合并不是遗漏。这是局部故障定位，不是认知编译算法已解决。

**已证伪／不得复跑**：
- 排他切分、按 Block/Line 数量评价认知质量。
- 用 Embedding、Path B 调参替代编译质量研究。
- 弱模型能力排名可判定强 Body 编译机制的有效性。
- 多阶段 Prompt 或增加审查必然无损；已有实际反例。
- 用「Stage A 条目数 > Stage B Block 数」判定交接损失：E1 同一方法 8 次报警，仅 3 个截止点存在经人工语义 witness 核对的遗漏（2 项独立认知）；合法合并和历史已存造成 5 次假阳性。
- 外部论文有现成可套的无损 SemanticBlock Compiler：未获证据支持。

**完成实验 E1（2026-10-08）**：只读远端重放 33 步真实旧推理回执；两条分阶段方法分别观察到文化认知和算力全生命周期认知在理解→Note 之间丢失；并行判断在理解层已经合并；回测提醒和替换对象的未决状态未获得独立维持；审查器误拒租金核验计划。两个理解条目合并为一条完整 Block 是合法反例。原始结果：[Actions #37751393698](https://github.com/Jasonatafricanow/LCE-Longitudinal-Cognition-Engine/actions/runs/37751393698)；研究代码：research/semantic_block_compiler/replay_e1.py。

**信息增益**：已明确区分上游理解失误、交接遗漏、准入误拒与合法合并；可证伪「靠输出数量对账」这一方法。此实验不证明泛化的自动语义核对器、强 Body 无损性或新 Compiler 成功。

**下一实验（未开工）**：只有重新满足信息增益门槛才开启 E2：用不在 E1 中的真实对话与强 Body，对照 GraphRAG 式定向追加补全 vs 直接编译；固定截止上下文，记录每项独立认知的来源及去向，重点看是否补回遗漏同时不引入伪造／过度拆分。Hindsight 式保留原始证据作为共同安全底线，不视为解决编译。不得拿旧的五节点答案重复证明强模型能理解。

**Stop condition**：S1 已触发——不同断点及合法合并均由冻结回执重放定位，本轮立即停止，不做额外模型／架构消融。E2 只有写明新增可排除解释并获得独立语料后才能开工；完成只更新本控制面，不追加综述。
